# Salo-Salo Filipino Fine Dining

Full-stack food ordering web application built with Node.js, Express, MongoDB, and React.

## Tech Stack
- Backend: Node.js, Express.js, MongoDB, JWT Auth
- Frontend: React (Vite), Axios

## Features
- Full CRUD menu management
- JWT Authorization
- Customer ordering with cart
- GCash, PayMaya, PayPal, Cash payment
- AI-powered customer service (Lola chatbot)
- Palawan-inspired Filipino theme

## Setup
1. Clone the repo
2. Run \
pm install\ in both folders
3. Add \.env\ file with your credentials
4. Run \
pm run dev\ in both folders
